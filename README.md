# Minimal Flask,HTMX and Alpne.js app with Authentication
## Introduction
  An app which demonstrates CRUD opperations using:
  1. Flask
  2. HTMX
  3. Alpine.js
## Installation Guide
###  1. Install Python Dependencies
 After cloning the repository  navigate to project directory run:
```
pip install -r requirements.txt 
```
### 2. Install Node Dependencies for TailwindCSS & DasiyUI (Required Only for further development)
```
 npm  install
```
### 3. Run the project
```
py app.py
```
### 4. Preview the Project
Open the browser and navigate to http://localhost:4000
